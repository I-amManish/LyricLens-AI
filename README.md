# LyricLens AI

> Don't just listen to music. Become the music.

An open-source, local-first creative music studio combining artificial intelligence, computer vision, touchless interaction, music visualization, karaoke, audio remixing, and personalized album artwork.

## Project Status

Under active development — early foundation stage.

## Planned Features

- Live webcam-based music visualization
- AI-powered body segmentation
- Lyrics surrounding the user's silhouette
- Touchless gesture-controlled music playback
- Beat-reactive animations
- Karaoke and vocal separation
- Music remixing and audio effects
- Personalized album cover generation
- Reference-based album artwork
- AI music generation
- Optional Gemini integration

## Getting Started

### Prerequisites

- Node.js compatible with the installed Vite version
- npm
- A modern web browser
- Webcam for upcoming interactive features

### Installation

```bash
cd frontend
npm install
npm run dev
```

### Testing

```bash
npm run test
npm run lint
npm run build
```
